JMA incorpora el feed Atom PULL oficial de alta frecuencia para detectar publicaciones relacionadas con tsunami; cada entrada debe contrastarse abriendo su XML original y no se clasifica automáticamente como alerta activa. CATAC, NWPTAC y SHOA se ofrecen como portales oficiales de consulta porque no se ha confirmado aquí un endpoint público de lectura directa desde navegador para esos centros. Consulte siempre la autoridad nacional correspondiente.
